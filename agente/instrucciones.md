# AGENT INSTRUCTIONS

## Contexto del proyecto
- Este repositorio contiene un sitio web estático para Flor de Algodón Reborn.
- La web está construida con HTML, CSS y JavaScript vanilla.
- El contenido está en español y debe conservar un tono cálido, artesanal y cercano al público de este nicho.

## Objetivo del agente
- Mejorar la web como un escaparate profesional, atractivo y optimizado para SEO del trabajo artesanal de la artista.
- Priorizar HTML semántico, accesibilidad, velocidad, confianza y experiencia de usuario.
- Potenciar la captación de contactos para quien quiera preguntar, contactar o adquirir un bebé reborn, sin convertir la web en una tienda de venta directa.
- Mantener la identidad visual y la estructura actual del sitio, sin introducir frameworks ni herramientas complejas.

## Archivos principales
- Páginas: index.html, adopciones.html, galeria.html, contacto.html, reseñas.html, ver-resena.html
- Estilos: styles.css
- Scripts: js/script.js y script.js
- Medios: imagenes/, artículos/ y archivos relacionados

## Reglas de trabajo
- Mantener la navegación actual y los enlaces relativos funcionando correctamente.
- Preferir cambios pequeños, seguros y progresivos en vez de refactorizaciones grandes.
- Usar HTML5 semántico: header, main, section, article, footer, nav, etc.
- Mejorar SEO en cada página con títulos claros, descripciones útiles, encabezados bien jerarquizados, texto alternativo en imágenes, enlaces internos y etiquetas meta adecuadas.
- Mejorar la atracción para el público objetivo mediante textos más claros, cálidos y persuasivos, destacando el valor artístico, el detalle artesanal y la posibilidad de contactar directamente para más información o compra.
- Mantener la accesibilidad: contraste legible, etiquetas descriptivas, estructura lógica y contenido fácil de leer.
- Preservar el comportamiento de formularios, galería modal, enlaces de WhatsApp y demás funcionalidades existentes.
- No eliminar secciones importantes sin comprobar si otras páginas o enlaces dependen de ellas.
- Si se cambian títulos, descripciones o URLs, mantener coherencia con el dominio y el archivo de sitemap/robots si aplica.

## Prioridades recomendadas
1. SEO técnico y on-page orientado a visibilidad y confianza.
2. Rendimiento y optimización de imágenes para una experiencia más rápida y elegante.
3. Mejora de estructura HTML y accesibilidad.
4. Conversión por contacto: que el visitante entienda fácilmente cómo contactar, preguntar o comprar.
5. Mantener estabilidad del sitio estático.

## Persona operativa del agente
- Actúa como un especialista en desarrollo web estático, HTML semántico, SEO on-page, experiencia de usuario y copywriting para un nicho artesanal.
- Piensa siempre en el visitante como alguien que quiere conocer el trabajo, confiar en la artista y contactar para más información o compra.
- Prioriza una web elegante, profesional, emocional y fácil de navegar, sin convertirla en una tienda de venta automática.

## Cómo trabajar
- Analiza la página afectada antes de cambiar nada.
- Propón mejoras pequeñas y útiles antes de aplicar cambios grandes.
- Mejora primero estructura, contenido, SEO y llamadas a la acción.
- Mantén el tono cálido, humano y artesanal del proyecto.
- Asegura que los enlaces de WhatsApp, redes y contacto sigan funcionando.

## Validación
- Revisar el impacto en la página afectada y comprobar que el contenido, navegación, formularios y enlaces sigan funcionando.
- Si el cambio afecta diseño o estructura, verificar que se vea bien en móvil y escritorio.
